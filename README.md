# GLIMMER - Premium Lounge Experience

![GLIMMER Hero](https://via.placeholder.com/1200x600?text=GLIMMER+Premium+Lounge)

A stunning, modern restaurant website for a premium tapas lounge and wine bar. Built with pure HTML, CSS, and JavaScript - no frameworks required.

## ✨ Features

### Visual Excellence
- **Custom cursor** with animated ring effect
- **Parallax particle system** in hero section
- **Smooth scroll reveals** with staggered animations
- **Marquee ticker** showcasing key offerings
- **Responsive gallery** with horizontal scroll and hover overlays
- **Metallic gold color palette** with deep midnight backgrounds

### Interactive Elements
- Dynamic navigation with scroll-triggered styling
- Tabbed menu system (Tapas, Mains, Drinks, Desserts)
- Interactive reservation form
- Mobile-friendly hamburger menu
- Hover animations on cards and buttons
- Gallery cells with overlay text on hover

### Sections
- **Hero** - Full-screen entrance with animated particles
- **About** - Story and statistics with badge animation
- **Menu** - Categorized food and beverage listings
- **Experience** - Feature cards highlighting unique offerings
- **Gallery** - Visual showcase of the lounge
- **Reservations** - Complete booking form
- **Testimonials** - Guest reviews and ratings
- **Footer** - Contact info, hours, and social links
